# 지식iN 원문 집중 조사 → 바로 최종 아웃풋 패치

- Focused Research에서는 후보 추천/순위/번호 선택/앱 import JSON 단계를 생략합니다.
- ChatGPT Pro가 내부적으로 게시 가치, 기존 글 중복, 에버그린성, 공식 근거, 고유 결과물을 검증합니다.
- 조사·검증형으로 통과하면 같은 응답에서 바로 `# 1. 게시용 본문` ~ `# 4. 네이버 지식iN 답변 추천`을 출력합니다.
- 직접 테스트가 반드시 필요하면 `[직접 테스트 필요]`에서 멈추며 결과를 상상하지 않습니다.
- 저가치/금지 분야/기존 글 중복이면 `[게시 보류]`합니다.
- 일반 `오늘의 자동 탐색`은 기존의 최대 3개 후보 심사 → 사용자 번호 선택 흐름을 그대로 유지합니다.
